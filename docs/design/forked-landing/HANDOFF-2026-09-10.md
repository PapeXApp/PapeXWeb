## 3. Nico's standing rules for the site
- **No em dashes in any user-visible copy** (all removed on 2026-09-10, including aria-labels and page
  metadata; verified `document.body.innerText` has none on `/`, `/customers`, `/business`). Use a comma,
  period, colon or parentheses. Comments are fine.
- **Playful and self-explanatory**: someone who doesn't read should still be able to play. Every
  interactive element needs an obvious affordance: button look, hover, pressed, a hint ("Tap to reveal").
- **Tight spacing**, no dead air inside cards.
- **Hover shows only the shape**: no glow or ring bleeding past rounded corners into a box.
- He judges by feel on his own screen, not by specs. Screenshots before "done".

## 5. Traps
- **Never `npm run build` while `npm run dev` is running** (shared `.next` → every route 500s; recover by
  stopping the server, `rm -rf .next`, restarting). During dev use `npx tsc --noEmit` + `npx next lint --file <path>`.
- `npm run lint` has 20 pre-existing failing files (listed in CLAUDE.md), none in the redesign folders. Keep it that way.
- CSS Modules won't rename a keyframe inside an `animation` shorthand that contains `var()`; use literal values or `animation-name`.
- `Reveal` writes an inline transform, so wrap cards: the wrapper takes the reveal, the card keeps `:hover`.
- The merchant dashboard is subdomain-only (`merchant.localhost:3001` locally); a 404 at `/merchant` on the main host is correct.
- `/r` is a real route and a Server Component on purpose; the AASA file + its headers in `next.config.ts` must not break (App Clip launches depend on them).
